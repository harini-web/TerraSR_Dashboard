What the model does

Important for interpreting results

Learned detail, not a new sensor capture.

Super-resolution increases output image dimensions and estimates fine structure. It does not reveal verified information beyond the original satellite measurement.

For geospatial analysis, use an RGB GeoTIFF and validate the predictions against independent high-resolution references.

HELP CENTER

How to use DeBlur

A straightforward guide to using the app and understanding the settings.

1. Add your trained model

Find best.pt from your project training run and place it in the following folder inside DeBlur: 

runs/exp1/best.pt

Alternatively, enter the full file path in Model settings. The app cannot predict without actual trained weights.

2. Upload and enhance

Click Enhance image in the left menu. Drag your low-resolution image to the upload box or choose Browse files. Click the purple Enhance image now button.

Wait for the completion message. You will see original, bicubic and CNN versions.

3. Compare and download

Slide the before/after comparison control. Click Download enhanced image to save the output. If you uploaded a GeoTIFF, you will receive a georeferenced TIFF; otherwise, you receive a PNG.

Which file should I upload?

Recommended: 3-band Sentinel-2 L2A RGB GeoTIFF made with your project's fetch_s2_rgb.py. PNG/JPG inputs are also supported. .npz test tiles can include both lr and hr arrays for evaluation.

To calculate PSNR/SSIM, provide the aligned HR reference in an NPZ pair. They cannot be measured from one LR image alone.

Current model limitations

The original project trains a 2× CNN by default, so a 10 m Sentinel-2 input produces a nominal 5 m output grid. A 3× checkpoint requires compatible 3× training. The extra pixels are learned estimates; geographic metadata are preserved for TIFF outputs, but the model cannot guarantee physically true fine detail.
